
| Begriff                             | Bounded Context    | Definition                                                                                                                                                                | Aliase / Verwandte Begriffe            |
| ----------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **Benutzerkonto**, **User Account** | Benutzerverwaltung | Der zentrale, administrative Datensatz für eine Person im System. Es enthält eine eindeutige ID, Anmeldeinformationen und ist mit einer oder mehreren `Rollen` verknüpft. | Account, User                          |
| **Rolle**, **Role**                 | Benutzerverwaltung | Eine zugewiesene Berechtigungsstufe, die bestimmt, welche Aktionen ein `Benutzerkonto` im System ausführen kann (z.B. die Rolle `Lehrer` oder `Schüler`).                 | Berechtigungsgruppe                    |
| **Klasse**, **Course**              | Benutzerverwaltung | Eine organisatorische Gruppe, die `Benutzerkonten` mit der `Rolle` `Schüler` zusammenfasst. Dient der Zuordnung von `Kursen`.                                             | Lerngruppe                             |
| **Schüler**, **Student**            | Benutzerverwaltung | Ein `Benutzerkonto` mit der `Rolle` `Schüler`, das einer `Klasse` zugeordnet ist. Repräsentiert die administrative Identität.                                             |                                        |
| **Lehrer**, **Teacher**             | Benutzerverwaltung | Ein `Benutzerkonto` mit der `Rolle` `Lehrer`, das erweiterte Rechte zur Erstellung und Verwaltung von Inhalten hat.                                                       |                                        |
| **Lehrer**, **Teacher**             | Unterrichten       | Der **Autor**, der `Lerneinheiten` und `Kurse` erstellt und deren Struktur festlegt.                                                                                      | Autor, Ersteller                       |
| **Lehrer**, **Teacher**             | Diagnostik         | Der **Analyst**, der aggregierte Leistungsdaten interpretiert, um den Lernfortschritt zu verstehen.                                                                       | Beobachter                             |
| **Schüler**, **Student**            | Lernen             | Der **Lernende**, der eine `Aufgabe` bearbeitet und `Abgaben` erzeugt. In diesem Kontext primär durch seine ID repräsentiert.                                             | Lernender                              |
| **Subject (sub)**, **student_sub**  | Übergreifend       | OIDC‑Subject einer Person (stabiler, opaker String ohne PII). Wird in APIs als `student_sub`/`teacher_id` transportiert; in DB‑Tabellen teilweise als `*_id` gespeichert (z. B. `course_memberships.student_id`). | OIDC sub, student_id (DB)              |
| **Kurs**, **Course**                | Unterrichten       | Eine organisatorische Hülle, die `Lerneinheiten` in einer bestimmten Reihenfolge für eine `Klasse` zusammenfasst und die `Freigaben` steuert.                             | Lehrveranstaltung                      |
| **Lerneinheit**, **Unit**           | Unterrichten       | Ein wiederverwendbarer, thematischer Inhaltsblock, der `Abschnitte` in einer definierten Reihenfolge enthält.                                                             | Modul, Themenblock, Unterrichtseinheit |
| **Abschnitt**, **Section**          | Unterrichten       | Eine thematische Unterteilung einer `Lerneinheit`, die `Material` und `Aufgaben` gruppiert. Ist die kleinste Einheit für eine `Freigabe`.                                 | Kapitel, Lektion                       |
| **Material**, **Material**          | Unterrichten       | Passiver, nicht-interaktiver Lerninhalt innerhalb eines `Abschnitts`. Unterstützt Markdown-Texte (`kind='markdown'`) und Datei-Materialien (`kind='file'`, Presigned Upload via `upload_intents`). | Inhalt, Ressource                      |
| **Aufgabe**, **Task**               | Unterrichten       | Eine interaktive Tätigkeit innerhalb eines `Abschnitts`, die eine `Abgabe` erfordert und `Kriterien` zur `Analyse` enthält.                                               | Übung                                  |
| **Kriterium**, **Criterion**        | Unterrichten       | Ein spezifischer Aspekt einer `Aufgabe`, anhand dessen eine `Abgabe` durch die KI analysiert wird (z.B. "Grammatikalische Korrektheit").                                  | Analysekriterium                       |
| **Freigabe**, **Release**           | Unterrichten       | Die Handlung des `Lehrers`, einen `Abschnitt` innerhalb eines `Kurses` für die Schüler sichtbar zu machen.                                                                | Sichtbarkeit schalten                  |
| **Abgabe**, **Submission**          | Lernen             | Eine unveränderliche Aufzeichnung der Lösung eines `Schülers` für eine `Aufgabe`. Löst eine `Analyse` aus und ist mit `Feedback` verbunden.                               | Einreichung, Versuch                   |
| **Analyse**, **Analysis**           | Lernen             | Das strukturierte Ergebnis, das die KI für eine `Abgabe` basierend auf den `Kriterien` generiert. Die Grundlage für das `Feedback`. In den APIs wird dies insbesondere über `analysis_json` (z.B. `TeachingLatestSubmission.analysis_json` im Schema `criteria.v1`/`criteria.v2`) repräsentiert. | Auswertung, Bewertung                  |
| **Rückmeldung**, **Feedback**       | Lernen             | Die KI-generierte, formative Rückmeldung, die ein `Schüler` zu einer spezifischen `Abgabe` erhält. In den APIs wird sie typischerweise als Markdownfeld `feedback_md` transportiert (z.B. `TeachingLatestSubmission.feedback_md`). | Rückmeldung                            |
| **Übungsmodul**, **Practice Module** | Unterrichten       | Ein besonderer Graphknoten einer modularen `Lerneinheit`, der ausschließlich wiederholbare native oder H5P-Aufgaben enthält. Er kann Eingangskanten besitzen, wird aber niemals `done` und darf keine ausgehenden Kanten besitzen. | Übungsstapel, Practice Stack           |
| **Übungsstapel**, **Practice Stack** | Lernen             | Die lernendenseitige Sicht auf ein offenes, nicht leeres `Übungsmodul`, dessen neue oder fällige Aufgaben für eine `Übungssitzung` ausgewählt werden können. | Übungsmodul                            |
| **Übungssitzung**, **Practice Session** | Lernen          | Ein fortsetzbarer, serverseitig gespeicherter Snapshot aus einem oder mehreren Übungsstapeln. Pro Lernendem existiert höchstens eine aktive Sitzung. | Practice Session                       |
| **Practice-Zustand**, **Practice State** | Lernen          | Der aktuelle, kurs- und aufgabenspezifische Wiederholungszustand eines Lernenden mit Stabilität, Intervall, Fälligkeit und Scheduler-Version. | Wiederholungszustand                   |
| **Einstufung**, **Classification**  | Lernen             | Die deterministisch aus dem Erfüllungswert abgeleitete sichtbare Kategorie `mastered`, `partial` oder `insufficient`. Das Sprachmodell legt sie nicht fest. | sicher, teilweise, nicht ausreichend  |
| **Unterstützter Abruf**, **Supported Recall** | Lernen    | Ein Versuch nach Einsicht in eine Musterlösung oder nach einer verpflichtenden Unterstützung. Er wird protokolliert, verändert aber Stabilität, Intervall und bestehende Fälligkeit nicht. | supported recall                       |
