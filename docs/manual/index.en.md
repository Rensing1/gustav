# GUSTAV Manual

GUSTAV-Version: 0.0.4
Last verified: 2026-08-20
[Deutsche Version](index.de.md)

This manual guides teachers through the complete classroom cycle: preparing a course, making content available, supporting learner work and reviewing learning processes. Each chapter also explains what learners see and what GUSTAV explicitly does not currently provide.

GUSTAV's product interface is currently in German. The English chapters therefore retain exact German control labels and explain them in English when they are first used.

## Coverage

The instructions describe the current product interface. GUSTAV is an early alpha release and may change. Sign-in, profiles, the concern box, the learner archive, the AI usage view, installation and server operation are outside this first manual release.

AI-generated feedback is formative. It supports reflection and revision, but does not replace a teacher's pedagogical judgement or final assessment.
