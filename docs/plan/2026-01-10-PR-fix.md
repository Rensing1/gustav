- [SEC] Prod‑CSP enthält `data'` (Syntaxfehler) — `backend/web/main.py:295@04c048f` — Impact: CSP greift falsch/gar nicht. — Fix: `data:` (ggf. `blob:`) + Test erweitern.
- [SEC] SECURITY‑DEFINER Helper `get_unit_latest_submissions_for_owner` ist nicht gehärtet (PUBLIC‑EXECUTE + unsafe `search_path` + Owner‑Binding via Parameter) — `supabase/migrations/20260108210000_teaching_live_h5p_completed.sql:19@04c048f` — Impact: unnötige Angriffs-/Leak‑Surface; Privilege‑Drift. — Fix: Folge‑Migration: `revoke all ... from public;` + `grant execute ... to gustav_limited;` + `set search_path = pg_catalog, public` (kein `pg_temp`) + Owner‑Check an Session (`app.current_sub`) binden (Parameter nicht zur Autorisierung verwenden).
- [SEC] Teaching‑CSRF ist nicht durchgängig strikt (env/flag‑abhängig) — `backend/web/routes/teaching.py:3056@04c048f` — Impact: CSRF‑Schutz hängt von ENV/Flag ab; Fehlkonfig möglich. — Fix: für alle mutierenden Teaching‑Endpunkte `_csrf_guard` (Origin/Referer Pflicht) nutzen; Branching entfernen.

## Entscheidungen (fixiert)
