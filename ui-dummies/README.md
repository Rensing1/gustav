# UI Dummies (Standalone)

These folders contain standalone, static UI prototypes (no GUSTAV backend, no docker-compose).

## Run

From the repo root:

```bash
python3 -m http.server 8000
```

Or:

```bash
npx http-server -p 8000
```

Open:

- http://localhost:8000/ui-dummies/
- http://localhost:8000/ui-dummies/student-workspace-hybrid-sticky/
